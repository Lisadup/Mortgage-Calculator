#Mortgage Calculator

#Overview

The Mortgage Calculator is a C# desktop application that calculates estimated monthly mortgage repayments based on user input. The application provides users with a simple interface for entering loan details and receiving accurate repayment calculations.

#Features

- Calculate monthly mortgage repayments
- Adjustable loan amount
- Adjustable interest rate
- Adjustable loan term
- Instant calculation results
- User-friendly interface

#Technologies Used

- C#
- .NET
- Windows Forms

#Installation

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Build the project.
4. Run the application.
